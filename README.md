An entry for the make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert": one satirical sentence about lawmakers who would regulate AI but cannot convert a file to PDF. The line sets up the senator's authority — drafting the bill to regulate artificial intelligence — then undercuts it with a specific, undignified detail: he emailed his staff a screenshot of a Word document and asked them to turn it into a PDF, with the punch landing on the last words.

## Run it

```sh
python3 main.py
```

Writes the entry sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default). Python 3.13, standard library only, no network access, deterministic.
